# Portfolio template — Nayem Mia

This branch adds a simple responsive single-page portfolio template with a glassmorphism/neon look.

Files added:
- index.html — main single-page layout
- css/styles.css — styles (glassmorphism, gradients, responsive)
- js/script.js — small interactions (theme toggle, mobile menu, smooth scroll)
- images/profile.svg — placeholder avatar (replace with your photo named `images/profile.svg`)

How to use:
1. Checkout branch `feature/portfolio`.
2. Open `index.html` in a browser.
3. Replace `images/profile.svg` with your real profile photo (same path) and update contact details in the HTML.
4. To enable a real CV download, replace the `#` on the Download CV button with your CV file link.
